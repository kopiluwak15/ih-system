# 💭 思考の外部化・整理・実行システム

## 概要

CEO の思考を自由に外部化し、課題を体系的に整理・管理するシステムです。

**主な機能：**
- 💬 独り言ページ - 自由にテキストで思考を述べる
- 📋 要約ページ - 時系列で思考の変化を追跡
- 🌳 課題管理 - ツリー構造で課題を並列管理
- 📊 思考分析 - 思考の変化を可視化
- 📅 ミーティング管理 - 緊急ミーティングをスケジューリング

## セットアップ

### 1. ZIP を解凍
```bash
unzip thinking-system.zip
cd thinking-system
```

### 2. ローカルサーバーを起動

**Python 3 の場合：**
```bash
python3 -m http.server 8000
```

**Node.js の場合：**
```bash
npx http-server -p 8000
```

### 3. ブラウザでアクセス
```
http://localhost:8000
```

## ファイル構成

```
thinking-system/
├── index.html              # メインページ（6ページSPA）
├── css/
│   └── styles.css         # 全体のスタイル
└── js/
    ├── storage.js         # localStorage管理
    ├── app.js             # アプリケーション統制
    ├── thought.js         # 独り言ページ
    ├── summary.js         # 要約ページ
    ├── issues.js          # 課題管理ページ
    ├── analysis.js        # 思考分析ページ
    └── meeting.js         # ミーティング管理ページ
```

## データについて

- **ローカルストレージ保存**：すべてのデータは browser の localStorage に保存されます
- **PC独立**：各PCで独立したデータベースとして動作します
- **データ移行**：別のPCに移行したい場合は、browser の localStorage をエクスポートしてください

## 使い方

### 1. プロジェクト作成
目標宣言ページで「やりたいことを宣言」

### 2. 独り言を述べる
独り言ページで、制限なく思考をテキストで表現

### 3. 要約を作成
「ここまで要約」ボタンで、その時点の思考を整理

### 4. 課題を管理
課題管理ページでツリー構造に整理

### 5. 進捗を追跡
各ページのタブで状況を確認

## 技術スタック

- **フロントエンド**：Vanilla JavaScript, HTML5, CSS3
- **データ保存**：localStorage（ブラウザ内のローカルDB）
- **フレームワーク**：なし（軽量・独立動作）
